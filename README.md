# Motorola Mobile-sales-Analysis-powerbi-dashboard | Power BI

## 📊 Overview

An interactive Power BI dashboard developed to analyze mobile sales
performance, customer behavior, product performance, and transaction trends.

## Objectives

- Analyze overall sales and transaction performance.
- Identify trends across months, brands, mobile models, and cities.
- Understand customer ratings and payment method preferences.
- Compare sales performance across different days.

##  Key KPIs

- Total Sales
- Total Quantity
- Total Transactions
- Average Sales

## 📊 Dashboard Analysis

The dashboard provides analysis of:

- Sales by City
- Quantity by Month
- Sales by Mobile Model
- Brand-wise performance
- Transactions by Payment Method
- Customer Ratings
- Sales by Day Name

## 🛠️ Tools Used

- Power BI
- Power Query
- DAX
- Data Visualization
- Data Cleaning & Transformation
